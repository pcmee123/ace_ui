# 图标规范

本包提供 85 个图标：独立 SVG、symbol sprite、JSON 路径数据与可选的原生 JS 渲染器。所有图标均按同一坐标、描边与命名规范整理。

- 坐标：24 × 24；默认描边 1.7；端点、连接圆角；fill=none；stroke=currentColor。
- 推荐显示尺寸：16 / 18 / 20 / 24px；图标和文字间距 8px。
- 装饰性图标 aria-hidden=true；只有图标的按钮必须在按钮上提供 aria-label。
- 不使用 emoji 替代系统图标，不混入不同线宽或实心风格。
- HTML 可使用 `data-ace-icon` 或直接内联 SVG；框架从 JSON 数据渲染 path；HTTP 环境可引用 sprite。
- standalone SVG 通过 img 引入时不会继承外层 currentColor。需要随主题变化时请内联，或使用框架图标组件。

命名采用小写短横线，例如 chevron-right、file-text。不存在的图标回退到 info，不读取任意用户路径或外部资源。

ACE UI 标识采用矢量构建，详见 assets/ace-mark.svg。图形资产用于当前设计系统；对外再分发前请核对所需授权。
