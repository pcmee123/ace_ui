# ACE UI 规范归一记录

版本：1.0.0 · 2026-11-18。

ACE UI 对颜色、尺度、图标和交互进行集中归一，作为独立设计语言交付。公开页面、文档和资源只使用 ACE UI 品牌。

## 颜色归一

默认石墨深色，以 #15181b 页面底、#101316 侧栏、#1b1f22 面板和 #00f09a 强调色建立层级。清透浅色、豆沙绿、深绿护眼以同样的语义角色映射颜色；状态色、输入边界、遮罩、代码底色统一集中在 tokens 内。

## 几何归一

控件、面板、弹窗圆角统一为 4 / 8 / 12px；侧栏 232px，顶栏 64px；以 4px 基础网格控制间距。四种主题只覆盖颜色，字体、间距、圆角、交互和响应式规则共享。

## 资源归一

图标统一为 24×24 坐标、1.7px 描边、圆角端点和 currentColor。原生交互遵循同一套焦点、键盘与语义规范。匿名参考指纹保存在 tokens/source-manifest.json，仅用于本地版本审计，不包含产品标识或本机源路径。

本交付包含 CSS、图标、静态页面、接入示例和中文规范；示例业务数据为本地演示。
