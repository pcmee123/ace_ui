# 主题与项目接入

## 资源分层

1. ace-tokens.css：主题颜色与共享尺度。
2. ace-base.css：仅作用于 .ace-ui 内的基础元素与焦点规则。
3. ace-components.css：跨业务可复用组件。
4. ace-layouts.css：骨架、网格、响应式模式。
5. ace-utilities.css：少量可组合的辅助类。

css/ace-ui.css 依次 @import 以上五份文件；dist/ace-ui.css 是内容一致的合并版本，只需要引入其中一种。showcase/showcase.css 是文档页视觉以及演示模板细节，不属于核心样式。复制页面模板时一起复制它；实际产品可自行替换该文件中的文档侧栏、品牌、图表和业务内容样式。

## 四皮肤

在 html 上设置 `data-ace-theme="dark|light|sage|eye"`。未设置时等同 dark。不要使用 data-theme，以免与旧产品冲突。可在局部容器设置 data-ace-theme 做嵌套预览；几何规则不会因此改变。

四种主题颜色集中定义在 ace-tokens.css，统一映射背景、面板、文字、强调与行动角色；状态色、控件边界、遮罩和代码底色为 ACE 语义扩展。主题声明只允许颜色相关变量与 color-scheme。字体、间距、圆角、控件高度、时长、断点一律放在共享区。

```js
AceUI.setTheme('dark'); // 主皮肤
AceUI.setTheme('light');
AceUI.setTheme('sage');
AceUI.setTheme('eye');
AceUI.getTheme();
document.addEventListener('ace:theme', event => {
  console.log(event.detail.theme);
});
```

原生全站主题选择写入 localStorage 的 `ace-ui.theme`；读写失败时依然切换当前页面，不阻止渲染。首次默认为 dark，后续尊重用户显式选择。需要防止闪烁时在 head、CSS 前同步引入 ace-theme-init.js。

## 原生行为属性

| 属性 / API | 行为 |
| --- | --- |
| data-ace-set-theme="sage" | 按钮换肤，自动同步 aria-pressed |
| data-ace-theme-select | select 换肤，选项为四个主题键 |
| data-ace-open="dialog-id" | 打开原生对话框或抽屉 |
| data-ace-close | 关闭所在对话框 |
| data-ace-toast="内容" | 显示本地轻反馈 |
| data-ace-copy="#code-id" | 复制指定元素 textContent |
| data-ace-icon="search" | ace-icons.js 将占位元素内容替换为 SVG |
| data-ace-nav-toggle | 切换所在 ace-shell 移动导航 |
| data-ace-nav-close | 关闭移动导航 |
| AceUI.init(container) | 初始化动态内容中的图标与 tabs |
| AceUI.copy(text) | 异步复制，失败会提示手动复制 |
| AceIcons.svg(name, size) | 返回可内联 SVG；name 限定在内置图标表 |
| AceUI.toast(text, {{duration: 5000}}) | 插入安全文本轻反馈 |

## Vue 与 React

ACE UI 保留框架中立。Vue / React 使用同一套 CSS 与变量；不要在框架已经控制的节点内调用图标 mount。可直接渲染 icons/ace-icons.json 路径数据。按钮、Dialog、Tabs 的状态和生命周期由框架管理，避免重复绑定。

`examples/vue/AceButton.vue`、`AceIcon.vue`、`AceThemeSwitch.vue`，以及 `examples/react/AceButton.tsx`、`AceIcon.tsx`、`AceThemeSwitch.tsx` 是可复制的源组件。它们依赖宿主项目自己的 Vue 3 / React / TypeScript；并非独立打包的 npm 组件库。React JSON 导入需 tsconfig 开启 resolveJsonModule，Vue/Vite 默认支持 JSON 导入。

## 其他技术栈

普通 HTML、Electron、Tauri、WebView 直接使用 dist CSS；Flutter、原生 Android/iOS 可把 tokens JSON 转译为平台主题，保留颜色角色、间距与圆角关系。此交付不包含这些原生平台的运行时组件。

## 浏览器约束

使用 CSS color-mix、CSS variables、原生 dialog、:focus-visible、100dvh 与 safe-area。应在目标项目支持的现代浏览器中验证；过旧的嵌入式 WebView 需要升级或由宿主提供兼容层。所有展示页无网络依赖，file:// 直接打开使用内联图标；外部 SVG sprite 推荐在 HTTP 环境下使用。
