## 稳定组件契约

### 按钮

基础 `ace-btn`，变体 `--primary`、`--soft`、`--ghost`、`--danger`，尺寸 `--sm`、默认、`--lg`；图标按钮 `--icon`，宽按钮 `--block`。主按钮使用 action/on-action，禁止把文本颜色写死为白色。加载态用 disabled、aria-busy=true 和 ace-spinner；保留业务重试路径。

### 表单

容器 `ace-field`，标签 `ace-label`，输入 `ace-input` / `ace-select` / `ace-textarea`。说明 `ace-field__help`，错误 `ace-field__error`。错误输入写 aria-invalid=true 并用 aria-describedby 关联提示。开关为原生 checkbox 加 ace-switch 与 role=switch；文件选择仅选中本地文件，上传需要业务 API。

### 容器与数据

卡片拆为 `ace-card__head`、`ace-card__body`、`ace-card__foot`。指标使用 `ace-stat__label`、`ace-stat__value`、`ace-stat__foot`。表格必须包在 ace-table-wrap 内；header 使用 scope=col，数据表有 caption，状态有文字，操作有带资源名的可读名称。

### 选项卡

tablist 内每个 role=tab 都有 id、aria-controls、aria-selected；对应 tabpanel 有 aria-labelledby。初始仅当前 tab tabindex=0，其余 -1。原生脚本处理左右箭头、Home/End 与面板 hidden；动态插入后调用 AceUI.init(container)。框架内按同样语义自行维护状态。

### 浮层

Dialog / Drawer 均为原生 dialog，以 data-ace-open="dialog-id" 打开，内部按钮 data-ace-close 关闭。必须有 aria-labelledby，表单提交时由业务逻辑决定何时 close()。原生对话框提供焦点约束与恢复；Escape 由浏览器处理。Drawer 只是 dialog 的几何变体，不单独实现交互。

Dropdown 使用 details / summary；Escape 或点击外部收起。它是通用操作列表，未伪装成需要特殊箭头键规范的 ARIA menu。Tooltip 同时响应 hover 与 focus-visible，且关键说明仍必须常显。

### 轻反馈

AceUI.toast(message) 插入 aria-live=polite 容器，最多 3 条，默认 5 秒；悬停或聚焦时暂停计时。不要用轻反馈替代必须处理的字段错误。Empty 必须解释现状并有下一步；Skeleton 对外暴露 aria-busy，减少动画偏好时停用动画。

## 页面模式

| 模板 | 布局 | 内置交互 |
| --- | --- | --- |
| dashboard.html | 侧栏 + 四指标 + 主次列 | 刷新提示、创建对话框、资源抽屉 |
| list.html | 筛选工具栏 + 表格 | 搜索、状态筛选、实际前端分页、无结果状态、详情 |
| settings.html | 分组表单 + 主题 | 换肤记忆、原生校验、重置、保存提示 |
| detail.html | 280px 摘要栏 + 详情 | 状态、配置、时间线、抽屉 |
| chat.html | 对话 + 上下文 | 预设提示、文本提交、安全文本渲染、本地示例回复 |
| login.html | 左品牌 + 右认证 | 邮箱/密码原生校验、演示成功提示 |
| mobile.html | 纵向卡片 + 底部导航 | 换肤、弹窗、资源详情、安全区 |
| starter.html | 空白应用骨架 | 可直接复制作为新应用起点 |

这些模板没有连接后台。真实业务接入时使用自身 API、认证和状态管理，并保持示例中的几何和语义变量。
