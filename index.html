配色的边界

背景提供层级

sidebar → bg → surface → surface-hover，使用亮度区分区域。常规卡片依赖 1px 边界，不依赖大阴影。

强调色引导行动

强调色用于主按钮、当前导航、焦点与关键图表。同一操作区域只出现一个主行动。

状态色表达意义

成功、警告、错误、信息各有独立语义变量；换肤时保持语义，配合文字和图标表达。

HTML / CSS
<!-- 只改变这个属性；其余 HTML、CSS 与交互保持一致 -->
<html lang="zh-CN" data-ace-theme="dark">
<!-- dark | light | sage | eye -->

<button class="ace-btn ace-btn--primary">创建项目</button>

/* 新组件引用语义变量，不直接写颜色 */
.project-card {
  background: var(--ace-surface);
  border: 1px solid var(--ace-border);
  border-radius: var(--ace-radius-md);
}

DESIGN STANDARDS

把一致性，变成可执行的规则。

用于设计、开发与评审的共同标准。让新页面延续现有项目的熟悉感。

01 / 视觉基调

深色优先，内容优先。

以石墨底、分层面板和细描边建立秩序。强调色只用于关键行动、选中项、焦点与必要的数据。避免大面积发光、装饰性渐变和没有信息意义的色块。

02 / 布局与密度

所有页面遵循同一副骨架。

桌面侧栏 232px，顶栏 64px；正文 32px，平板 24px，手机 16px。采用 4px 基础网格；卡片间隔 16px，章节间隔 24–32px。侧栏在 760px 及以下改为可展开导航。

03 / 排版与数字

让层级来自字重与留白。

正文 13–14px，说明 12px，章节标题 20px，页面标题 28px，展示标题 36px。正文行高 1.6，中文说明不压缩字距；统计数字、时间、ID 使用等宽字体和等宽数字。10px 英文眉题仅作辅助装饰，关键信息必须有正常字号。

04 / 圆角与边界

小圆角，轻边界。

控件 4px，面板 8px，对话框 12px；圆形仅用于头像变体、状态点和开关。边界 1px，焦点 2px；常规卡片无投影，浮层才使用阴影。不要让主题改动这些几何规则。

05 / 行动与状态

每个操作区域，一个明确主行动。

主按钮使用 action/on-action；危险按钮使用 danger，并在实际删除前使用确认对话框。区分默认、悬停、聚焦、按下、禁用与加载。异步任务期间防止重复提交，失败后保留输入并提供重试。

06 / 无障碍

键盘路径与视觉路径保持一致。

所有输入有可见标签；错误说明用 aria-describedby 关联。焦点始终可见；对话框使用原生 dialog，关闭后恢复焦点；tabs 使用方向键和 roving tabindex。颜色之外补充文字与图标；表格可横向滚动。

07 / 对比度与触摸

常规文字优先可读。

关键正文目标对比度至少 4.5:1，大字至少 3:1；faint 仅用于非关键信息，必要正文使用 text 或 text-secondary。border 为装饰分界，输入边界用 border-strong。粗指针控件至少 44px，开关与复选框由标签扩展触摸范围。

08 / 动效

动效解释变化，不制造负担。

悬停 140ms，展开 200ms，采用统一 ease。避免无限装饰动画；加载动画适量。遵循 prefers-reduced-motion，停用骨架屏与旋转动画，不用动效承载唯一的状态信息。

09 / 空、错、加载

让每种状态都有下一步。

空状态说明为什么为空，并给一个创建或清除筛选操作；错误区分网络、权限与校验；加载保留原有空间，长任务给可读进度。消息 Toast 用于轻反馈，阻塞问题使用页面或字段错误。

10 / 换肤规则

只覆盖颜色，不复制组件。

四种主题共用一份组件 CSS；主题块只覆盖颜色、阴影色和 color-scheme。新增产品色必须映射到语义变量。禁止在业务 CSS 中散落十六进制颜色；禁止为不同皮肤另写布局与字号。
