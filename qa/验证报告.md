# ACE UI 1.0 验证报告

验证日期：2026-11-18。实际环境：Windows、本机 Chrome / Chromium、Playwright。

## 已通过

- 静态检查：18 个 HTML / CSS 文件的本地引用、ARIA ID 关联、CSS 变量与单文件 CSS 一致性；85 个图标文件完整。
- 布局检查：7 个展示分区 + 8 个独立模板，分别在 4 种皮肤、1440px 与 390px 下检查，共 120 个组合，无整页横向溢出。
- 换肤检查：按钮的宽高、内边距、字号、圆角在四主题间一致；主题选择可保存、刷新后恢复；首次无偏好时为 dark。
- 对话框：初始焦点、Escape 关闭、关闭后恢复焦点、表单提交。
- 键盘与导航：Tabs 方向键 / Home、下拉 Escape、移动导航展开与关闭、折叠侧栏 inert。
- 数据列表：搜索、状态筛选、实际前端分页、无结果、清除条件、详情抽屉。
- 组件：示例分页、分段控制、图标搜索 / 复制 SVG、本地文件选择、Toast。
- 表单与对话：邮箱及密码约束生效；对话输入按文本渲染，HTML 不执行。
- 本地交付：file:// 直接打开、四主题切换、资源列表筛选可用。
- 页面脚本错误 0、丢失的运行时资源 0、外部运行时请求 0。
- 产品名称清理：公开页面、文档与资源仅保留 ACE UI 品牌。

## 预览与复现

`screenshots/` 保存四主题桌面总览、390px 总览、组件页以及移动 / 列表 / 设置 / 登录页面截图。`results.json` 是浏览器检查的实际输出。

```sh
node preview.mjs
node scripts/check.mjs
# 在已有 Playwright 的环境中，按需设置 PLAYWRIGHT_MODULE 与 CHROME_PATH

```

Vue / React 文件为宿主项目接入源示例，未单独安装框架编译；Firefox、Safari 与旧 WebView 未在本次环境中运行。认证、聊天、上传和保存均为明确标注的界面演示，业务 API 由后续应用接入。
